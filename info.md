# Amber Electric Integration

Real-time wholesale electricity prices, forecasts, spike alerts, daily usage, and NEM grid renewables for Amber Electric customers in Australia.

### Quick Setup
1. Generate an API token at [app.amber.com.au/developers](https://app.amber.com.au/developers).
2. Add the **Amber Electric** integration via **Settings → Devices & Services**.
3. Enter your API token and select your site.
